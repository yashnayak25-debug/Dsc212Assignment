#  The Karate Club Story
The Karate Club graph is a well-known social network studied by anthropologist Wayne W. Zachary in the early 1970s. It represents friendships and interactions among 34 members of a university karate club, connected by 78 edges.
During the study, a disagreement between the instructor (“Mr. Hi”) and the club president led to the club splitting into two factions. The network is a classic benchmark for community detection because its recorded friendships can be compared with the actual division.
In this assignment, we use spectral modularity partitioning to identify communities from the network structure and examine how closely the detected groups reflect the underlying social relationships.
